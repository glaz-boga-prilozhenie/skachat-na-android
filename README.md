# Приложение «Глаз Бога»: как пользоваться на Android

Для поиска на Android откройте Telegram и перейдите к боту по действующей ссылке. Отдельный APK-файл для этого не требуется. Если Telegram ещё не установлен, скачайте его из привычного магазина приложений и войдите в свой аккаунт обычным способом.

## Порядок действий

1. Откройте страницу со ссылкой на бота.
2. Перейдите в Telegram и выберите подходящий тип поиска.
3. Отправьте номер, ник с `@` или числовой Telegram ID.
4. Проверьте дату и детали совпавших записей.

## Что делать с запросом «скачать на Android»

Если страница предлагает скачать неизвестный установочный файл ради доступа к поиску, сначала проверьте, зачем он нужен и кто его разместил. Для описанного здесь сценария достаточно Telegram. Не вводите пароль от Telegram и одноразовый код на сторонней странице.

Внутри бота состав ответа зависит от совпадений в доступных записях. Например, по номеру могут встретиться связанные аккаунты, а по нику или ID прежние имена. Старые сведения проверяйте по дате: контакт и ник могли измениться.

## Если ссылка не открылась

Убедитесь, что Telegram установлен и обновлён, затем повторите переход из браузера. Если приложение предложит выбрать способ открытия ссылки, укажите Telegram. Для поиска не требуется переносить личные данные из результата в другие приложения.
